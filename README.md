# ПравоРеклама — проверка рекламы на правовые риски РФ

Веб-приложение (MVP) для проверки рекламных коммуникаций на соответствие
законодательству Российской Федерации: ФЗ-38 «О рекламе», КоАП РФ (ст. 14.3),
ФЗ-152 «О персональных данных», ФЗ-436 «О защите детей от информации»,
Закон «О защите прав потребителей».

По каждому найденному риску приложение показывает:

- **описание** нарушения и цитату из рекламы;
- **правовое основание** — закон и статью;
- **уровень риска** — низкий / средний / высокий / критический;
- **меры минимизации** — как исправить;
- **ответственность** — статью КоАП и диапазон штрафов (граждане / должностные / юрлица);
- **практику ФАС / судов** — при наличии в базе.

> ⚠️ **Дисклеймер.** Результаты формируются автоматически, носят
> информационно-справочный характер и **не являются юридической консультацией**.
> Правовая база и размеры штрафов могут устаревать — перед принятием решений
> проконсультируйтесь с юристом. База знаний (`backend/app/knowledge/*.yaml`)
> подлежит выверке специалистом.

## Как это работает (гибрид)

```
Ввод (текст / URL / изображение)
        │
        ▼
Нормализация в текст  (картинка → OCR/vision, URL → парсинг страницы)
        │
        ├─▶ Движок правил (детерминированно): стоп-слова, превосходная
        │   степень, отсутствие ERID/маркировки, категории товаров,
        │   обязательные дисклеймеры, сбор персданных
        │
        └─▶ LLM (Claude): смысловой анализ контекста и скрытых рисков
        │
        ▼
Слияние и дедуп находок → отчёт со «светофором» и карточками рисков
```

Движок правил работает **всегда**, в т.ч. без API-ключа. LLM-слой добавляет
смысловой анализ и включается при наличии `ANTHROPIC_API_KEY`.

## Поддерживаемые входы

- **Текст** — объявления, посты, слоганы.
- **URL / лендинг** — загрузка страницы и анализ её текста.
- **Изображение** — креативы (PNG/JPG/WEBP); текст распознаётся через
  vision-модель Claude, запасной вариант — Tesseract OCR.

## Быстрый старт (Docker)

```bash
cp .env.example .env      # при желании впишите ANTHROPIC_API_KEY
docker compose up --build
```

- Фронтенд: http://localhost:8080
- API (Swagger): http://localhost:8000/docs

## Запуск без Docker

### Бэкенд

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...     # опционально — включает ИИ-анализ
uvicorn app.main:app --reload --port 8000
```

Быстрый смоук-тест ядра (без сети и LLM):

```bash
python smoke_test.py
```

### Фронтенд

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173 (проксирует /api на :8000)
```

## Структура проекта

```
backend/
  app/
    api/          # роуты FastAPI (/api/analyze, /api/analyze/image, /api/health)
    ingest/       # приём контента: text, url, image (OCR/vision)
    rules/        # движок правил + морфология (pymorphy3)
    knowledge/    # ПРАВОВАЯ БАЗА (YAML): laws, liability, categories, rules, practice
    llm/          # адаптер провайдера (Claude / заглушка) + промпт
    analysis/     # оркестратор пайплайна
    models.py     # pydantic-модели (Finding, Report)
  smoke_test.py
frontend/
  src/            # React + TypeScript: ввод, отчёт, карточки рисков
docker-compose.yml
```

## Правовая база знаний

Вся правовая логика вынесена в редактируемые YAML-файлы
`backend/app/knowledge/` — их можно пополнять без изменения кода:

| Файл | Назначение |
|------|-----------|
| `laws.yaml` | Реестр законов и статей (ФЗ-38, 152-ФЗ, 436-ФЗ и др.) |
| `liability.yaml` | Ответственность (КоАП) и размеры штрафов |
| `categories.yaml` | Категории с особым режимом (алкоголь, табак, БАД, финансы…) |
| `rules.yaml` | Правила детекции (превосходная степень, маркировка, персданные…) |
| `practice.yaml` | Примеры практики ФАС / судов |

## Что покрывает MVP

- ✅ Общие требования ФЗ-38: превосходная степень, некорректное сравнение,
  гарантии результата, отсутствие существенной информации.
- ✅ Маркировка интернет-рекламы: ERID, пометка «реклама», рекламодатель,
  возрастная маркировка.
- ✅ Ограниченные категории: алкоголь, табак/вейпы, лекарства и медуслуги,
  БАД, финансы/кредиты, азартные игры, детская реклама.
- ✅ Персональные данные (152-ФЗ) и защита несовершеннолетних.
