# Деплой публичного сервера (с проверкой картинок)

Публичный сервер нужен, чтобы анализировать **рекламу-картинки/баннеры**: «зрение»
работает на бэкенде (Claude vision по API-ключу; без ключа — запасной OCR Tesseract).
Статический сайт на GitHub Pages картинки анализировать не может — там нет сервера.

Один контейнер (корневой `Dockerfile`) поднимает FastAPI, который отдаёт **и интерфейс,
и API** по одному адресу.

---

## Вариант 1 — Render (рекомендуется, бесплатно, без карты)

1. Зайди на https://render.com и войди через GitHub.
2. **New +** → **Blueprint**.
3. Выбери репозиторий `Alisa7753191/-reklama` и ветку
   `claude/russian-ad-compliance-app-pvdnvh` (или ту, куда смержишь).
   Render прочитает `render.yaml` и создаст web-сервис `pravoreklama`.
4. Нажми **Apply** — пойдёт сборка Docker (несколько минут).
5. Открой сервис → **Environment** → добавь секрет:
   - `ANTHROPIC_API_KEY` = твой ключ Anthropic (для распознавания картинок «зрением»
     и ИИ-анализа смысла). Ключ берётся в консоли Anthropic.
   - (уже задан) `ANTHROPIC_MODEL` = `claude-opus-4-8`.
6. **Manual Deploy → Deploy latest commit** (чтобы подхватить ключ).
7. Готовый адрес вида **`https://pravoreklama.onrender.com`** — это и есть ссылка на
   агента. Вкладка **«Изображение»** принимает баннеры.

> Бесплатный план засыпает после простоя — первый заход после паузы грузится ~30–50 сек.
> Проверка здоровья: `/api/health`.

## Вариант 2 — Hugging Face Spaces (бесплатно)

1. https://huggingface.co → **New Space** → **Docker** (пустой шаблон), порт `7860`.
2. Залей в Space содержимое репозитория (или подключи GitHub-зеркало).
3. **Settings → Variables and secrets** → добавь секрет `ANTHROPIC_API_KEY`.
4. Space соберёт `Dockerfile` и даст адрес вида `https://<user>-<space>.hf.space`.

---

## Локально (для проверки)

```bash
docker build -t pravoreklama .
docker run -p 7860:7860 -e ANTHROPIC_API_KEY=sk-ant-... pravoreklama
# открой http://localhost:7860
```

Без ключа приложение тоже работает: текст и URL проверяются правилами полностью,
картинки распознаются запасным OCR (Tesseract, rus+eng) — качество ниже, визуальные
сигналы (логотип vs фирменное наименование, видимость erid) не оцениваются.

---

## Что от чего зависит

| Возможность | Без `ANTHROPIC_API_KEY` | С ключом |
|-------------|--------------------------|----------|
| Текст / URL (движок правил) | ✅ полностью | ✅ + ИИ-анализ смысла |
| Картинки/баннеры | ⚠️ OCR Tesseract (только текст) | ✅ Claude vision (текст + визуальные сигналы) |

> Использование ключа = платные обращения к Anthropic API (по тарифам Anthropic).
